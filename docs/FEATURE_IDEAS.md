# Идеи фич для Aura Editor (замена Fleet)

Текущий стек: Electron + React + Monaco + xterm/node-pty. Обновлено после реализации
git-интеграции, доп. фич вкладок, диагностики и улучшений поиска — см. "Уже реализовано" ниже.

## Уже реализовано

- **Вкладки** — несколько открытых файлов одновременно, переключение, закрытие (`Cmd+W`
  или крестик на вкладке), индикатор несохранённых изменений. Можно выключить в Settings
  (тогда открытие файла заменяет текущий, как раньше).
  - **Pinned tabs** — закрепление вкладки (иконка pin на вкладке), чтобы её нельзя было
    случайно закрыть (крестик на закреплённой вкладке спрашивает подтверждение).
  - **Reopen closed tab** (`Cmd+Shift+T`) — вернуть последнюю закрытую вкладку.
  - **Переупорядочивание вкладок** drag & drop.
- **Settings-страница** (иконка шестерёнки в тулбаре) — Tabs, Autosave, режим плотности
  интерфейса Mode (micro/compact/normal/large), сторона сайдбара (Sidebar: left/right),
  Git, Diagnostics, и справочный список горячих клавиш. Настройки хранятся в
  `userData/settings.json`.
- **Git-интеграция** — статусы файлов в дереве (M/A/U/D/staged, цветной бейдж), diff-вьюер
  (Monaco `DiffEditor` поверх HEAD), минимальная git-панель (переключатель Files/Git в
  сайдбаре): staged/unstaged, discard/revert для файла (`git checkout HEAD --` для
  отслеживаемых, удаление в корзину для untracked), commit, push/pull, текущая ветка.
  Работает через системный `git` CLI, обновляется автоматически по тому же file watcher,
  что и дерево файлов. Можно выключить в Settings ("Git"). Blame по строке — не
  реализован, остаётся как возможное отдельное улучшение на будущее.
- **Commit-палитра по `Cmd+K`** — быстрый доступ к git-панели (commit/revert/push/pull)
  модальным окном, не переключая сайдбар в режим Git.
- **Диагностика** — TypeScript/JavaScript через встроенный Monaco TS-worker (бесплатно,
  достаточно стабильной модели на файл); Python — проверка синтаксиса через `ast.parse`
  (без side-effect файлов); ESLint — только если в открытом проекте есть свой локальный
  `node_modules/.bin/eslint` (конфиг самой Aura никогда не применяется к чужому проекту).
  Можно выключить в Settings ("Diagnostics"). Автокомплит с доступом к типам всего
  проекта (`addExtraLib`) не реализован — остаётся отдельной более крупной задачей.
- **Drag & drop файлов из Finder/Explorer** — перетащить файл в окно, чтобы открыть его.
- **Быстрый поиск (двойной Shift)** — ищет и файлы, и папки; пути показываются
  относительно корня воркспейса, а не абсолютные системные; выбор папки раскрывает и
  прокручивает к ней дерево вместо попытки открыть как файл.
- **Иконки при наведении в дереве файлов** — на `.py` файле появляется иконка запуска
  (Run Script), на `.md` — иконка предпросмотра (Preview), по аналогии с иконками New
  File/New Folder у папок.
- **Файловые операции** — create/rename/delete (через `shell.trashItem`, т.е. в корзину ОС),
  copy/paste (`Cmd+C`/`Cmd+V` при фокусе на дереве, с авто-переименованием при конфликте
  имён), drag & drop между папками.
- **`.gitignore`** учитывается в дереве и в глобальном поиске, поверх встроенного списка
  игнора (`node_modules`, `dist`, и т.п.).
- **File watcher** — дерево и открытый файл обновляются при внешних изменениях (git,
  другой редактор), с защитой от собственных self-write событий и баннером
  Reload/Ignore при конфликте с несохранёнными правками.
- **Autosave** — через 1.2с простоя (можно выключить в Settings).
- **Тема следует за ОС** (light/dark), Monaco переключается между `vs`/`vs-dark`.
- **Markdown preview** — переключатель source/preview для `.md`.
- **Сворачивание markdown-заголовков (`#`) в редакторе** — свой
  `monaco.languages.registerFoldingRangeProvider('markdown', ...)` в `monaco-setup.ts`
  (Monaco изначально это не поддерживает — folding по заголовкам в VS Code идёт от
  отдельного markdown-расширения, которого нет в core-бандле).
- **Find & Replace в файле** — встроено в Monaco (`Cmd+F`).

Хлебные крошки были реализованы и затем сознательно убраны по решению пользователя —
не стоит возвращать их без явного запроса.

## Не делаем (сознательно отложено)

- **Command Palette (Cmd+Shift+P)** — единая точка входа для всех действий.
- **Replace across workspace** — сейчас `GlobalSearch` только ищет, замены по всему
  воркспейсу нет.
- **Go to Symbol / Outline** — список функций/классов в файле.
- **Recent files (Cmd+E)** — список недавно открытых файлов шире, чем текущие вкладки.
- **Расширение Settings точечными опциями редактора** (word wrap toggle, minimap toggle,
  tab size) — density-режимов пока достаточно.
- **Zoom in/out (Cmd+/Cmd-)** — временный оверрайд размера шрифта поверх Mode.
- **Split editor** — два файла рядом (горизонтально/вертикально).
- **HTML/Image preview** — по аналогии с markdown preview.
- **Task runner / npm scripts panel**.
- **Debugger** (DAP) — отдельная крупная задача, если понадобится.
- **Больше языков для "Run"** (сейчас только python3).
- **Тема терминала** отдельно от темы приложения.
- **Множественные окна**.
- **Zen mode / distraction-free**.
- **Spell-check** для markdown/текстовых файлов.

## Возможные следующие шаги (не запрошено, просто заметки)

- Git blame по строке.
- Project-wide TS/JS автокомплит (`addExtraLib`, чтение `node_modules/@types`).
- Мультикурсор — Monaco поддерживает из коробки, стоит перепроверить, что шорткаты не
  блокируются.
- **ESLint fix-on-save** — раз диагностика ESLint уже подключена (используя локальный
  eslint открытого проекта), логично туда же добавить опциональный `--fix` при сохранении.
