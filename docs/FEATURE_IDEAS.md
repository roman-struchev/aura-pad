# Идеи фич для AuraPad (замена Fleet)

Текущий стек: Electron + React + Monaco + xterm/node-pty. Обновлено после git-интеграции,
переименования в AuraPad и раунда мелких UX-правок — см. "Уже реализовано" ниже.

## Уже реализовано

- **Вкладки** — несколько открытых файлов одновременно, переключение, закрытие (`Cmd+W`
  или крестик на вкладке), индикатор несохранённых изменений. Можно выключить в Settings
  (тогда открытие файла заменяет текущий, как раньше).
  - **Pinned tabs** — закрепление вкладки (иконка pin на вкладке), чтобы её нельзя было
    случайно закрыть (крестик и `Cmd+W` на закреплённой вкладке спрашивают подтверждение —
    централизовано в `closeTab`, а не только в UI).
  - **Reopen closed tab** (`Cmd+Shift+T`) — вернуть последнюю закрытую вкладку.
  - **Переупорядочивание вкладок** drag & drop.
  - Панель вкладок скрывается, если открыт только один файл — заголовок окна и так
    показывает, что открыто.
- **Settings-страница** (иконка шестерёнки в тулбаре), сгруппирована по смыслу: внешний вид
  (Theme dark/light/system, Mode-плотность, Line Numbers, Sidebar left/right), поведение
  редактирования (Tabs, Autosave), панели-фичи (Git, Diagnostics), и сворачиваемый (по
  умолчанию свёрнутый) список горячих клавиш. Настройки хранятся в `userData/settings.json`.
- **Сайдбар** — ширина тянется мышкой и сохраняется между запусками; по умолчанию слева.
  Переключатель Files/Git оформлен как отдельная изолированная рамка внутри сайдбара
  (не на всю ширину, как хедер), не завязан на высоту панели вкладок.
- **Git-интеграция** — статусы файлов в дереве (M/A/U/D/staged, цветной бейдж, скрывается
  и заменяется иконкой действия при наведении, если действие есть), diff-вьюер (Monaco
  `DiffEditor` поверх HEAD), git-панель: staged/unstaged, discard/revert для файла
  (`git checkout HEAD --` для отслеживаемых, удаление в корзину для untracked), commit,
  push/pull, текущая ветка, счётчик добавленных/удалённых строк (`git diff --numstat`)
  рядом с файлом. Несколько открытых git-репозиториев переключаются табами внутри
  git-панели, а не показываются один под другим. `Cmd+K` — переключить сайдбар на
  вкладку Git. Работает через системный `git` CLI (порядок разбора `status`/`diff` — через
  `-z`, без проблем с квотированием путей с пробелами/юникодом). Можно выключить в Settings
  ("Git"). Blame по строке — не реализован, остаётся как возможное отдельное улучшение.
- **Диагностика** — TypeScript/JavaScript через встроенный Monaco TS-worker (бесплатно,
  достаточно стабильной модели на файл); Python — проверка синтаксиса через `ast.parse`
  (без side-effect файлов); ESLint — только если в открытом проекте есть свой локальный
  `node_modules/.bin/eslint` (конфиг самой AuraPad никогда не применяется к чужому проекту).
  ESLint- и Python-проверки запускаются только при первом открытии файла и повторно после
  реального сохранения — не при каждом переключении на уже открытую вкладку, поскольку сам
  процесс `eslint` — это ~1-2 секунды на файл при type-aware конфиге, и гонять его при
  каждом клике по вкладке было ощутимо медленно. Можно выключить в Settings ("Diagnostics").
  Автокомплит с доступом к типам всего проекта (`addExtraLib`) не реализован.
- **Редактор** — номера строк можно выключить в Settings; узкий скролл (5px) — и в Monaco,
  и у обычных HTML-скроллов (вкладки, дерево) через `::-webkit-scrollbar`, для единого вида.
- **Drag & drop файлов из Finder/Explorer** — перетащить файл в окно, чтобы открыть его.
- **Быстрый поиск (двойной Shift)** — ищет и файлы, и папки; пути показываются
  относительно корня воркспейса, а не абсолютные системные; выбор папки раскрывает и
  прокручивает к ней дерево вместо попытки открыть как файл.
- **Иконки при наведении в дереве файлов** — на `.py` файле появляется иконка запуска
  (Run Script, только hover-иконка — убрали дублирующий пункт из контекстного меню),
  на `.md` — иконка предпросмотра (переключает preview/source повторным нажатием).
- **Файловые операции** — create/rename/delete (через `shell.trashItem`, т.е. в корзину ОС),
  copy/paste (`Cmd+C`/`Cmd+V` при фокусе на дереве, с авто-переименованием при конфликте
  имён), drag & drop между папками. Fix: `Cmd+C`/`Backspace`/`Delete` больше не перехватываются,
  когда фокус на самом деле в текстовом поле внутри сайдбара (например, в поле commit
  message git-панели) — раньше Backspace там мог случайно предложить удалить файл.
- **`.gitignore`** учитывается в дереве и в глобальном поиске, поверх встроенного списка
  игнора (`node_modules`, `dist`, и т.п.).
- **File watcher** — дерево и открытый файл обновляются при внешних изменениях (git,
  другой редактор), с защитой от собственных self-write событий и баннером
  Reload/Ignore при конфликте с несохранёнными правками.
- **Autosave** — через 1.2с простоя (можно выключить в Settings).
- **Тема** — dark/light/system в Settings (по умолчанию system, следует за ОС).
- **Markdown preview** — переключатель source/preview для `.md`.
- **Сворачивание в markdown-редакторе** — свой
  `monaco.languages.registerFoldingRangeProvider('markdown', ...)` в `monaco-setup.ts`:
  заголовки `#`, блоки кода в тройных бэктиках/тильдах, YAML frontmatter в начале файла.
  Побочный эффект: полностью отключает штатный indentation-based fallback складывания
  Monaco для markdown — вложенные списки больше не сворачиваются "бесплатно". Не
  переделано намеренно (вложенные списки в доках этого проекта неглубокие).
- **Find & Replace в файле** — встроено в Monaco (`Cmd+F`).
- **Заголовок окна** — всегда показывает имя приложения (AuraPad), а не имя открытого
  файла — оно и так видно на активной вкладке.

Хлебные крошки были реализованы и затем сознательно убраны по решению пользователя —
не стоит возвращать их без явного запроса.

## Не делаем (сознательно отложено)

- **Command Palette (Cmd+Shift+P)** — единая точка входа для всех действий.
- **Replace across workspace** — сейчас `GlobalSearch` только ищет, замены по всему
  воркспейсу нет.
- **Go to Symbol / Outline** — список функций/классов в файле.
- **Recent files (Cmd+E)** — список недавно открытых файлов шире, чем текущие вкладки.
- **Zoom in/out (Cmd+/Cmd-)** — временный оверрайд размера шрифта поверх Mode.
- **Split editor** — два файла рядом (горизонтально/вертикально).
- **HTML/Image preview** — по аналогии с markdown preview.
- **Task runner / npm scripts panel**.
- **Debugger** (DAP) — отдельная крупная задача, если понадобится.
- **Больше языков для "Run"** (сейчас только python3).
- **Тема терминала** отдельно от темы приложения.
- **Множественные окна**.
- **Zen mode / distraction-free**.
- **Spell-check** для markdown/текстовых файлов.

## Возможные следующие шаги (не запрошено, просто заметки)

- Git blame по строке.
- Project-wide TS/JS автокомплит (`addExtraLib`, чтение `node_modules/@types`).
- Мультикурсор — Monaco поддерживает из коробки, стоит перепроверить, что шорткаты не
  блокируются.
- **ESLint fix-on-save** — раз диагностика ESLint уже подключена (используя локальный
  eslint открытого проекта), логично туда же добавить опциональный `--fix` при сохранении.
- **Git stash/pop** — сейчас в git-панели только stage/unstage/discard/commit/push/pull;
  быстрый stash перед переключением контекста — частый сценарий, которого не хватает.
- **Commit history / log** — простой список последних коммитов текущей ветки (`git log`)
  в git-панели или отдельной вкладке, без клейма на полноценный git log viewer.
- **Close all tabs / Close other tabs** — сейчас можно закрыть только одну вкладку за раз
  (крестик или `Cmd+W`); типовое действие в контекстном меню вкладки, которого пока нет
  (контекстного меню у вкладок вообще нет — только hover-иконки).
- **Amend last commit** — чекбокс рядом с полем commit message в git-панели.
