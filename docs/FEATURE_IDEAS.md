## Возможные следующие шаги (не запрошено, просто заметки)
- перевод текста
- Git blame по строке.
- Project-wide TS/JS автокомплит (`addExtraLib`, чтение `node_modules/@types`).
- Мультикурсор — Monaco поддерживает из коробки, стоит перепроверить, что шорткаты не
  блокируются.
- **ESLint fix-on-save** — раз диагностика ESLint уже подключена (используя локальный
  eslint открытого проекта), логично туда же добавить опциональный `--fix` при сохранении.
- **Git stash/pop** — сейчас в git-панели только stage/unstage/discard/commit/push/pull;
  быстрый stash перед переключением контекста — частый сценарий, которого не хватает.
- **Commit history / log** — простой список последних коммитов текущей ветки (`git log`)
  в git-панели или отдельной вкладке, без клейма на полноценный git log viewer.
- **Amend last commit** — чекбокс рядом с полем commit message в git-панели.
