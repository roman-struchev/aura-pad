# Идеи фич для Aura Editor (замена Fleet)

Текущий стек: Electron + React + Monaco + xterm/node-pty. Обновлено после реализации
вкладок и страницы настроек — см. "Уже реализовано" ниже за полным списком.

## Уже реализовано

- **Вкладки** — несколько открытых файлов одновременно, переключение, закрытие (`Cmd+W`
  или крестик на вкладке), индикатор несохранённых изменений. Можно выключить в Settings
  (тогда открытие файла заменяет текущий, как раньше).
- **Settings-страница** (иконка шестерёнки в тулбаре) — тумблеры для Tabs, Breadcrumbs,
  Autosave, настройки хранятся в `userData/settings.json`.
- **Файловые операции** — create/rename/delete (через `shell.trashItem`, т.е. в корзину ОС),
  copy/paste (`Cmd+C`/`Cmd+V` при фокусе на дереве, с авто-переименованием при конфликте
  имён), drag & drop между папками.
- **`.gitignore`** учитывается в дереве и в глобальном поиске, поверх встроенного списка
  игнора (`node_modules`, `dist`, и т.п.).
- **File watcher** — дерево и открытый файл обновляются при внешних изменениях (git,
  другой редактор), с защитой от собственных self-write событий и баннером
  Reload/Ignore при конфликте с несохранёнными правками.
- **Autosave** — через 1.2с простоя (можно выключить в Settings).
- **Breadcrumbs** над редактором, кликабельные (можно выключить в Settings).
- **Тема следует за ОС** (light/dark), Monaco переключается между `vs`/`vs-dark`.
- **Markdown preview** — переключатель source/preview для `.md`.
- **Find & Replace в файле** — встроено в Monaco (`Cmd+F`).

## 1. Git-интеграция (в Fleet — одна из ключевых фич, у нас пока нет)

- Значки статуса файлов в дереве (modified / added / untracked / staged).
- Diff-вьюер для изменённого файла (Monaco умеет diff editor "из коробки").
- Минимальная git-панель: staged/unstaged, commit, push/pull, просмотр текущей ветки.
- Blame по строке (опционально, позже).

## 2. Навигация и командный доступ

- **Command Palette (Cmd+Shift+P)** — единая точка входа для всех действий (open file,
  toggle terminal, format, run script, settings, git actions и т.п.), в духе Fleet/VS Code.
- **Replace across workspace** — сейчас `GlobalSearch` только ищет, замены по всему
  воркспейсу нет.
- **Go to Symbol / Outline** — список функций/классов в файле (для TS/JS можно получить
  через Monaco + TypeScript language service).
- **Recent files (Cmd+E)** — список недавно открытых файлов, отдельно от полнотекстового
  поиска.
- **Restore session** — при перезапуске приложения восстанавливать открытые вкладки,
  активный файл, ширину сайдбара, позицию курсора.

## 3. Редактор

- **Мультикурсор / множественный выбор** — Monaco поддерживает из коробки, надо только
  не блокировать шорткаты (сейчас, кажется, не блокируются — стоит перепроверить).
- **Split editor** — открыть два файла рядом (горизонтально/вертикально), как
  split-панели в Fleet.
- **Настройки редактора** — font size (сейчас хардкод 14), zoom (Cmd+/Cmd-), tab size,
  word wrap toggle, minimap toggle. Логично добавить в уже существующую Settings-страницу.
- **HTML/Image preview** — markdown preview уже есть; по аналогии открыть картинку —
  показать превью вместо попытки прочитать как текст.

## 4. Языковые фичи (то, что в Fleet идёт "из коробки" через LSP)

- **Diagnostics/lint inline** — хотя бы TypeScript через встроенный `monaco-editor` TS
  worker (уже в зависимостях), плюс ESLint через отдельный процесс.
- **Autocomplete/IntelliSense** для TS/JS уже частично есть в Monaco по умолчанию —
  стоит проверить, включена ли подгрузка typings проекта (сейчас, вероятно, нет доступа
  к `node_modules/@types`).
- **Format on save** (Prettier) — сейчас ручное форматирование есть только для JSON.

## 5. Терминал и запуск

- **Task runner / npm scripts panel** — показать `package.json` → `scripts` и запускать
  по клику, а не только "Run Script" для `.py`.
- **Debugger** — сложнее, но для Node/Python можно интегрировать через DAP (Debug Adapter
  Protocol) — большая фича, стоит рассматривать отдельно.
- **Больше языков для "Run"** (сейчас только python3), например по расширению файла
  (`.js` → node, `.sh` → bash и т.п.).
- **Тема терминала** — сейчас xterm всегда тёмный (сознательно, чтобы не выглядеть
  разнобойно со светлой темой приложения); можно сделать её тоже переключаемой.

## 6. Разное / полировка UX

- **Множественные окна** — сейчас `createWindow` вызывается один раз; Fleet позволяет
  открыть разные проекты в разных окнах.
- **Drag & drop файлов из Finder/Explorer** — открыть файл, перетащив его в окно
  приложения (сейчас drag & drop работает только внутри дерева файлов).
- **Zen mode / distraction-free** — скрыть сайдбар и хедер по хоткею.
- **Spell-check** для markdown/текстовых файлов.

---

### Рекомендованный порядок реализации

1. Git-статусы в дереве + diff-вьюер (минимальная git-интеграция) — самый заметный
   оставшийся разрыв с полноценной IDE.
2. Command Palette.
3. Split editor + настройки редактора (font size, tab size, word wrap, minimap) в
   Settings-странице.
4. Diagnostics/autocomplete для TS/JS, format on save.
